# Data folder

Put the real dataset here, named `cardekho.csv`. It is not included in the repository.

1. Create a free account at kaggle.com.
2. Search for "Vehicle dataset from CarDekho" and download `CAR DETAILS FROM CAR DEKHO.csv`.
3. Rename it to `cardekho.csv` and place it in this folder.

Then train the model from the `backend` folder: `python -m app.train`
